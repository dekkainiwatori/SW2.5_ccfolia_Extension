# ココフォリア SW2.5 ダイスカットイン補助拡張機能 (Ccfolia SW2.5 Dice Cut-in Helper)

このChrome/Edge拡張機能は、TRPGオンラインセッションツール「ココフォリア」上でのソード・ワールド2.5（SW2.5）のダイス結果を監視し、特定の出目が出た際に自動でカットイン用のコマンドをチャットに入力・送信します。

## 機能

*   **技能判定の自動送信**:
    *   `[6,6]`（自動成功）が出た場合、自動で `@自動成功` を送信します。
    *   `[1,1]`（自動失敗）が出た場合、自動で `@自動失敗` を送信します。
*   **威力表（ダメージダイス）の自動送信**:
    *   クリティカル（〇回転）が発生した場合、自動で `@クリティカル` を送信します。
    *   `[1,1]`（自動的失敗）が出た場合、自動で `@ファンブル` を送信します。
*   **GM用除外機能（誤爆防止）**:
    *   モンスターの固定ダメージダイス（2d6）などが技能判定として誤認識されるのを防ぐため、ダイスコマンドに **`[D]`** という記号が含まれている場合は、自動判定処理をスキップします。
    *   使用例：`2d6+12 [D] 爪ダメージ`

## インストール方法（Chrome / Edge 共通）

この拡張機能はストアには公開されていないため、「デベロッパーモード」を使用して手動で読み込む必要があります。

1.  **拡張機能管理画面を開く**
    *   **Google Chrome** の場合: アドレスバーに `chrome://extensions/` と入力してEnter。
    *   **Microsoft Edge** の場合: アドレスバーに `edge://extensions/` と入力してEnter。
2.  **デベロッパーモードをオンにする**
    *   画面の右上（Edgeの場合は左下のメニュー内）にある「**デベロッパーモード**（開発者モード）」のスイッチをオン（有効）にします。
3.  **フォルダを読み込む**
    *   画面に新しく表示される「**パッケージ化されていない拡張機能を読み込む**（Load unpacked）」ボタンをクリックします。
4.  **フォルダを選択**
    *   この `README.md` や `manifest.json` が入っているフォルダを選択してください。
5.  **インストール完了**
    *   一覧に「Ccfolia SW2.5 Dice Cut-in Helper」が表示され、スイッチがオンになっていればインストールは完了です。

## 使い方

1.  拡張機能をインストールしたブラウザで、ココフォリアのルームを開きます。
2.  通常通りダイスボット（SwordWorld2.5）を使用して判定やダメージロールを行ってください。
3.  条件を満たす出目が出た瞬間、自動的に指定のコマンドが入力・送信され、カットインが発動します。
    *   ※ご自身のアカウントで事前に `@自動成功` や `@クリティカル` 等のカットイン設定（ココフォリアのルーム設定）を行っておく必要があります。

## バージョンアップ・修正を反映させる場合

プログラム（`content.js`など）を書き換えた後は、拡張機能管理画面（`edge://extensions/`）を開き、この拡張機能のパネルにある**「再読み込み（更新マークのボタン）」**をクリックすることで最新の状態が反映されます。その後、ココフォリアのページをリロード（F5）してください。
